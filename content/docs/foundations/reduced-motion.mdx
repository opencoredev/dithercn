<ComingSoon />

When `prefers-reduced-motion: reduce` is set, animated pieces render a single, carefully chosen frame instead of a loop. Nothing needs to be configured for that.

## Planned

- Still-frame fallback for every animated piece, on by default.
- A `reducedMotion` prop for pieces where a slow crossfade is still acceptable.
- Docs for each piece showing its reduced-motion frame next to the animated one.
