A landing page hero and a dashboard with twenty sparklines have very different budgets. The defaults will favour the dashboard: render once, re-render only on resize or data change, and never block the main thread during scroll.

## Planned

- One canvas per piece, sized by ResizeObserver, re-rendered only when inputs change.
- A server-rendered placeholder at the final size, so pieces don't cause layout shift.
- OffscreenCanvas in a worker for error diffusion on large images.
- Published numbers per piece: bundle size and render time on a mid-range phone.
