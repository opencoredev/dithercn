Pass an image source and get back a dithered rendering in theme ink and paper. Error diffusion will be the default here because it gives the best result on photos.

## Planned

- Any algorithm from the dither engine.
- Brightness, contrast and threshold controls.
- A build-time path that outputs a static PNG, so there is no runtime cost.
