## Usage

```tsx
import { HoverReveal } from "@/components/dithercn/hover-reveal";

export function Feature() {
  return (
    <HoverReveal
      src="/photos/studio.jpg"
      alt="The studio floor before opening"
      className="aspect-4/3 w-full rounded-xl"
    />
  );
}
```

With a mouse or pen, a spotlight follows the pointer and the photo shows through it. Its edge is dithered too, so the hole has the same texture as the image around it. On touch, a tap reveals the whole photo and a second tap brings the dither back. Keyboard focus reveals the whole photo.

## Examples

### Dissolve on hover, in a gallery

`reveal="dissolve"` dissolves the whole dither away instead of opening a spotlight. The Bayer 4 method gives each card the same regular grain.

## Notes

- The original is a real `<img>` with your alt text, so screen readers and search engines see the photo. The dithered layer is hidden from them.
- Give the component a size: it fills its box, it does not take the image's ratio.
- With reduced motion, the dither switches off and on without the spotlight or the dissolve.
- The animation runs only while the reveal is moving, at up to 60 fps, and stops once it settles.
