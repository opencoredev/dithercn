## Usage

```tsx
import { DitherImage } from "@/components/dithercn/dither-image";

export function Cover() {
  return (
    <DitherImage
      src="/photos/launch.jpg"
      alt="The launch pad at dawn"
      className="aspect-video w-full rounded-xl"
    />
  );
}
```

The image fills its box like `object-fit: cover`. Give the box a width and either a height or an aspect ratio; with only a width, it takes the image's own ratio once it loads, or `ratio` if you set it.

Dark parts of the image take the darkest palette colour and light parts the lightest. On a black page with the default palette the highlights are drawn in ink; on a white page the shadows are. Either way the picture reads as a positive.

## Examples

### Six methods

`method` picks the algorithm. The ordered matrices (`bayer4`, `bayer8`, `blue-noise`) give a regular texture that stays stable if the image changes. Error diffusion (`floyd-steinberg`, `atkinson`, `sierra-lite`) keeps finer detail. Atkinson, the default, drops a little of the error, which gives clean highlights and deep shadows.

### Four colours

`palette` takes two to four colours. Here blue noise spreads the Hubble photo over the page colour and three chart blues, sorted from dark to light.

A larger `cell` and the `bayer8` matrix give a bolder print. Setting `--dither-paper` on the image matches the paper to the card it sits in.

## Notes

- The root has `role="img"` and your `alt` text as its label. With `alt=""` it is hidden from assistive technology.
- The image loads when it comes within about 300px of the viewport, then fades in. It redraws when the box resizes, the page zooms or the theme changes.
- Dithering runs once per change on the main thread, at one pixel per cell. A 1200 by 800 pixel box at the default 2px cell is 600 by 400 cells, 240,000 pixels.
