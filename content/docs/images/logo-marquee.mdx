## Usage

```tsx
import { LogoMarquee } from "@/components/dithercn/logo-marquee";

const logos = [
  { src: "/logos/acme.svg", alt: "Acme", ratio: 4 },
  { src: "/logos/globex.svg", alt: "Globex", ratio: 3.5 },
];

export function Customers() {
  return <LogoMarquee logos={logos} label="Customers" />;
}
```

Every logo is a [Dithered logo](/docs/images/dithered-logo) with the same cell, matrix, shade and colour, so logos from different brands read as one set. The row repeats as many times as it needs to fill the width and loops without a seam. Each end fades into the background through eight dithered steps.

`ratio` on each logo reserves its width before it loads, so the row does not shift.

## Examples

### Wall

`variant="wall"` lays the logos out in a still grid with hairline dividers, two to four columns depending on the width of its container. With `shimmer`, a band of ink passes through each logo in turn.

## Notes

- The logos are a list labelled by `label`, and each logo is labelled with its alt text. The repeated copies that fill the loop are hidden from assistive technology.
- The marquee pauses while the pointer or keyboard focus is on it, and while it is offscreen.
- With reduced motion, the marquee becomes a still, centred row that wraps onto more lines as needed.
- The motion is a single transform animation on the row, so it stays smooth while the page is busy.
