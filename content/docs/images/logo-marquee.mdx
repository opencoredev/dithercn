## Usage

```tsx
import { LogoMarquee } from "@/components/dithercn/logo-marquee";

const logos = [
  { src: "/logos/acme.svg", alt: "Acme", ratio: 4 },
  {
    src: "/logos/globex.svg",
    alt: "Globex",
    ratio: 3.5,
    href: "/customers/globex",
  },
];

export function Customers() {
  return <LogoMarquee logos={logos} label="Customers" />;
}
```

Every logo is a [Dithered logo](/docs/images/dithered-logo) with the same fill, cell and colour, so logos from different brands read as one set. The row repeats as many times as it needs to fill the width and loops without a seam.

Hover or focus the row and it coasts to a stop instead of halting; let go and it picks up speed again. A small pause button appears at the right end on hover and keyboard focus. The ends fade out through a mask, so the fade works on any background: `soft` is a smooth ramp, `dither` steps through Bayer levels.

`ratio` on each logo reserves its width before it loads, so the row does not shift. Give a logo an `href` to make it a link.

## Examples

`variant="wall"` lays the logos out in a still grid with hairline dividers, two columns, or four once its container is 672px wide. Each logo links to a case study, and the shimmer passes through them in turn.

## Notes

- The first copy of the row is a list labelled by `label`; the copies that fill the loop are hidden from assistive technology and their links are out of the tab order.
- The row stops while it is offscreen. Under reduced motion it becomes a still, centred row that wraps.
- The motion is a single Web Animation on a transform, so it runs off the main thread.
