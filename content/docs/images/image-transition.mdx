## Usage

```tsx
import { ImageTransition } from "@/components/dithercn/image-transition";

const images = [
  { src: "/photos/coast.jpg", alt: "The coast at low tide" },
  { src: "/photos/ridge.jpg", alt: "A ridge above the cloud line" },
] as const;

export function Showcase() {
  return (
    <ImageTransition
      images={images}
      className="aspect-video w-full rounded-xl"
    />
  );
}
```

Every image is dithered once to the same grid. During a dissolve each cell switches to the next image when the progress passes its threshold in a Bayer matrix, with a gentle drift from the top left so the change travels across the frame.

Without `index`, the slideshow moves on every `interval` milliseconds. It pauses while the pointer is over it, while it is offscreen and while the tab is hidden.

## Notes

- The root has `role="img"` labelled with the current image's alt text. Changes are not announced, so a slideshow does not interrupt a screen reader.
- Autoplay content that moves on its own needs a way to stop it. The component pauses on hover; for longer slideshows, add a pause button that sets `index`, or pass `interval={0}`.
- With reduced motion, images switch instantly.
- A dissolve costs one pass over the cells per frame, copying whole pixels. The frame loop runs only while a dissolve is in progress.
