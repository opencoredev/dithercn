## Usage

```tsx
import { ImageCompare } from "@/components/dithercn/image-compare";

export function Showcase() {
  return (
    <ImageCompare
      src="/photos/launch.jpg"
      alt="The launch pad at dawn, dithered and original"
      className="w-full rounded-xl"
    />
  );
}
```

Drag the divider, click anywhere on the image to send it there, or tab to the handle and use the arrow keys. By default the left side is dithered with the `duotone` preset and the right side is the original photo. When the image first comes into view, the divider nudges left and right once so readers see that it moves.

Each side is either `{ kind: "original" }` or `{ kind: "dither", ...look }`, where the look takes the same props as [Dither image](/docs/images/dither-image): `preset`, `color`, `palette`, `method`, `cell` and the rest.

## Notes

- The handle is a `role="slider"` with a value from 0 to 100. Arrow keys move it by 1, Shift and arrow or Page Up and Page Down by 10, Home and End to the ends.
- Clicks glide the divider over 200ms; drags and key presses follow exactly.
- On touch screens a sideways drag moves the divider and a vertical swipe still scrolls the page.
- Under reduced motion there is no hint and no glide.
