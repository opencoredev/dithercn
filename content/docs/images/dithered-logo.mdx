## Usage

```tsx
import { DitheredLogo } from "@/components/dithercn/dithered-logo";

export function Brand() {
  return <DitheredLogo src="/logo.svg" alt="Acme" className="h-8" />;
}
```

Set a height with `className`; the width follows the logo's own ratio. The logo is drawn at a 1px cell, fine enough for small type, and its ink thins towards the bottom. Its own colours are ignored: every part becomes the one ink colour.

## Examples

### One treatment for many logos

Logos from different brands, drawn with the same cell, matrix and shade, sit together as a set.

### Colour and shade

`shade={0}` draws solid ink, here in the foreground colour. Higher values thin the ink further; with `shade={0.85}` and blue noise the bottom of the wordmark breaks into grain.

## Notes

- The root has `role="img"` with the brand name as its label.
- SVGs need a `width` and `height` (or a `viewBox` the browser can size) so the logo has a ratio.
- The shimmer runs at 30 fps only while the logo is on screen, and stops under reduced motion. Without it, the logo is drawn once and redrawn only on resize or theme change.
