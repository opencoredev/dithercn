## Usage

```tsx
import { DitheredLogo } from "@/components/dithercn/dithered-logo";

export function Brand() {
  return <DitheredLogo src="/logo.svg" alt="Acme" className="h-8" />;
}
```

Set a height with `className`; the width follows the logo's own ratio. The logo is drawn on a grid of whole device pixels and cut at half coverage, so every edge lands on a cell boundary instead of fraying into noise. A solid outline one cell wide keeps the shapes exact, and the inside takes the `fill`: a gradient that thins towards the bottom, dots, hatching, or solid ink.

By default every part of the logo becomes one ink, `color`. With `tone="original"` it keeps the file's own colours.

## Notes

- The root has `role="img"` with the brand name as its label.
- SVGs need a `width` and `height` (or a `viewBox` the browser can size) so the logo has a ratio. SVGs are rasterised by the browser at the exact cell size, so curves stay smooth.
- Effects run at 30 fps only while the logo is on screen, and stop under reduced motion. Without one, the logo is drawn once and redrawn only on resize or theme change.
