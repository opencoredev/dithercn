## Usage

```tsx
import { Sparkline } from "@/components/dithercn/sparkline";

export function RevenueTrend() {
  return (
    <Sparkline
      data={[41, 43, 42, 46, 48, 47, 51, 54]}
      label="Revenue, last 8 weeks"
      className="w-24"
    />
  );
}
```

A sparkline takes a plain array of numbers, oldest first. Its height is a prop and its width follows the element, so set it with `className` or let it fill a table cell. By default the value range fits the data, because a sparkline shows the shape of a trend. Pass the same `domain` to every sparkline in a column when the rows should be compared.

`label` is required. Screen readers hear it followed by a summary of the data, such as "Revenue, last 8 weeks: 41 to 54, low 41, high 54".

## Examples

### In a table

Each row's trend sits in its own cell at 24px high. `dot={false}` keeps a column of sparklines quiet.

<ComponentPreview src="examples/sparkline-table.tsx">

### Line only, one in ink

`area={false}` drops the fill. Each row shares `domain={[0, 180]}`, so a flat service draws flat instead of stretching its small wobble to full height, and the one spike drawn in ink is the first thing you see.

## Notes

- By default the sparkline is a single image to assistive technology, named by `label` and a summary of its first, last, lowest and highest values, with no readout; show the exact number next to it. With `interactive` it becomes a focusable group: the arrow keys move a gliding dot and a polite live region reads each value.
- On entrance the line draws in, the fill fades up and the dot appears last. With reduced motion it appears finished.
- It runs no animation loop and costs one small SVG, so a table with dozens of rows stays cheap.
