## Usage

```tsx
import { RadarChart } from "@/components/dithercn/radar-chart";

export function Evals() {
  return (
    <RadarChart
      axes={["Reasoning", "Coding", "Math", "Writing", "Vision"]}
      series={[
        { label: "Model v3", values: [86, 91, 78, 72, 64] },
        { label: "Model v2", values: [71, 74, 69, 76, 40] },
      ]}
      max={100}
    />
  );
}
```

Axes run clockwise from 12 o'clock. Each series lists one value per axis in the same order. Without `max`, the outer ring sits at a round number above the largest value.

Every series is a polygon of whole dither cells with a solid one-cell outline and square markers on its corners. With `fill="gradient"` the density steps up once per ring, thin at the centre and dense near the rim, so the grid reads straight through the shape. Each series takes the next palette colour. Where series overlap their cells interleave, so neither hides the other, and every outline stays on top.

Move the pointer around the chart and the readout snaps to the nearest axis, with every series' value there. Focus the chart and the arrow keys step around the axes. Hover a legend entry to spotlight a series, click to keep it lit, and press Escape to let go.

The chart fills its container up to `size` and shrinks with it, keeping room for the labels.

## Notes

- The chart is a focusable group with a summary label. The arrow keys move between axes, a live region reads each axis's values, and a hidden table lists every value.
- The shapes grow out from the centre once when the chart scrolls into view. With reduced motion they appear at once and the readout moves without easing.
- The drawing is one SVG path per series, built from whole cells snapped to device pixels. Scrubbing only moves the readout by transform and restyles one spoke.
