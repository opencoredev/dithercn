## Usage

```tsx
import { AreaChart } from "@/components/dithercn/area-chart";

const data = [
  { month: "Jan", revenue: 18400 },
  { month: "Feb", revenue: 21900 },
  { month: "Mar", revenue: 26300 },
];

export function Revenue() {
  return (
    <AreaChart
      data={data}
      x="month"
      series={[{ label: "Revenue", value: "revenue" }]}
    />
  );
}
```

`data` can hold any objects. `x` names the field with each point's label and every series names the field with its value. Both also accept a function, such as `(datum) => datum.total / 100`, when you render the chart from a Client Component. The chart fills its container's width and redraws when the container resizes.

## Examples

### Two layered series

With two or more series the chart adds a legend, and every series after the first draws in a different colour and dither texture (an 8×8 Bayer, then a 2×2). Each fill knocks out the ones behind it, so overlapping areas never mix and the lines always sit on top. Hover or focus the chart and use the arrow keys to read every series at one point.

<ComponentPreview src="examples/area-chart-layered.tsx" size="lg">

### Compact, inside a stat card

`axes={false}` drops the axes and the padding around the plot, so the fill can run to the edges of a card. `fill="flat"` uses one even level, and `matrix="bayer8"` gives a finer texture.

## Notes

- The chart is a focusable group labelled with a short summary, and the full data sits in a visually hidden table, so screen readers get every value. The arrow keys, Home and End move the readout; Escape hides it.
- On entrance the line draws in and the fill steps up through the dither levels. With reduced motion the finished chart appears at once.
- Cells are snapped to whole device pixels, so the dither stays sharp on any screen. Markers use a ring in `--dither-paper`; set it to your card's background if the card is not the page colour.
- It is plain SVG with no chart library. The entrance re-renders the chart about 16 times, then it only redraws on hover.
