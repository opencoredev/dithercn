## Usage

```tsx
import { AreaChart } from "@/components/dithercn/area-chart";

const data = [
  { month: "Jan", revenue: 18400 },
  { month: "Feb", revenue: 21900 },
  { month: "Mar", revenue: 26300 },
];

export function Revenue() {
  return (
    <AreaChart
      data={data}
      x="month"
      series={[{ label: "Revenue", value: "revenue" }]}
    />
  );
}
```

`data` can hold any objects. `x` names the field with each point's label and every series names the field with its value. Both also accept a function, such as `(datum) => datum.total / 100`, when you render the chart from a Client Component. The chart fills its container's width and redraws when the container resizes.

## Examples

### Two layered series

With two or more series the chart adds a legend, and every series after the first draws in the next palette colour. Each fill knocks out the ones behind it, so overlapping areas never mix and the lines always sit on top. Scrub with the pointer, or focus the chart and use the arrow keys: a crosshair and readout glide between points. Hover a legend entry to spotlight that series, click it to keep it lit, and press Escape to let go.

### Compact, inside a stat card

`axes={false}` drops the axes and the padding around the plot, so the fill can run to the edges of a card. `fill="dotted"` swaps the gradient for a sparse, even lattice of dots.

## Notes

- The chart is a focusable group labelled with a short summary, and the full data sits in a visually hidden table, so screen readers get every value. The arrow keys, Page Up, Page Down, Home and End move the readout without easing, a polite live region reads out the values at each stop, and Escape clears the readout and any locked series. Legend entries are toggle buttons.
- On entrance the line draws in and the fill steps up through the dither levels. With reduced motion the finished chart appears at once.
- Cells are snapped to whole device pixels, so the dither stays sharp on any screen. Markers use a ring in `--dither-paper`; set it to your card's background if the card is not the page colour.
- It is plain SVG with no chart library. The entrance re-renders the chart about 16 times. Scrubbing updates at most once a frame and only moves the crosshair, markers and readout, by transform, so a year of daily points in three series stays smooth.
