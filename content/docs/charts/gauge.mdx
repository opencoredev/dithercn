## Usage

```tsx
import { Gauge } from "@/components/dithercn/gauge";

export function CpuGauge({ load }: { load: number }) {
  return <Gauge value={load} label="CPU load" unit="%" />;
}
```

The arc is split into blocks. Blocks up to the value fill in, with the block at the value solid and each one behind it a step lighter, so the arc points at the reading. The rest of the track stays as faint dots.

## Examples

### Dials on a host card

`variant="dial"` sweeps 270°, like a speedometer. A gauge over 90% switches its `color` to `--destructive`.

<ComponentPreview src="examples/gauge-dial.tsx">
  <GaugeDial />
</ComponentPreview>

### Ring beside a summary

`variant="ring"` is a full circle starting at the top, with the reading in the middle. It hides the min and max labels, which would sit on top of each other.

## Notes

- The gauge has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-valuetext` that includes the unit. The drawing is hidden from assistive technology.
- Blocks fade in one after another when the gauge appears or the value rises. With reduced motion turned on they appear at once.
- It is plain SVG with one pattern per density, so it costs nothing after it renders.
