## Usage

```tsx
import { Gauge } from "@/components/dithercn/gauge";

export function CpuGauge({ load }: { load: number }) {
  return <Gauge value={load} label="CPU load" unit="%" />;
}
```

The arc is split into blocks over a faint track in the same colour. Blocks up to the value fill in, and the block at the value is solid and steps out by one cell, so the arc points at the reading like a needle. With `fill="gradient"` each block behind it is a step lighter; `dotted`, `hatched` and `solid` fill evenly.

## Examples

### Dials on a host card

`variant="dial"` sweeps 270°, like a speedometer. A gauge over 90% switches to `color="red"` with `fill="hatched"` and a low bloom, so it reads as a warning without relying on colour alone.

<ComponentPreview src="examples/gauge-dial.tsx">
  <GaugeDial />
</ComponentPreview>

### Ring beside a summary

`variant="ring"` is a full circle starting at the top, with the reading in the middle, here in `green` with `fill="dotted"`. It hides the min and max labels, which would sit on top of each other.

## Notes

- The gauge has `role="meter"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-valuetext` that includes the unit. The drawing is hidden from assistive technology.
- Blocks fade in one after another when the gauge appears or the value rises. With reduced motion turned on they appear at once.
- It is plain SVG with one pattern per density, so it costs nothing after it renders. Bloom is a blurred copy of the filled blocks.
