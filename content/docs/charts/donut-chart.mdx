## Usage

```tsx
import { DonutChart } from "@/components/dithercn/donut-chart";

const data = [
  { label: "North America", value: 48210 },
  { label: "Europe", value: 31870 },
  { label: "Asia Pacific", value: 17430 },
];

export function Regions() {
  return <DonutChart data={data} label="Requests today" />;
}
```

Segments run clockwise from the top in the order you pass them. In one ink, each segment is a step lighter than the one before, so put the largest first. Five densities are available before they repeat; past that, give segments their own `color`.

Hovering a segment or its legend row brings it forward and shows its value in the centre.

## Examples

### Colour per segment

Each segment sets `color` from the theme's chart colours and the same `level`, so colour carries the difference. `matrix="bayer8"` gives a finer texture.

## Notes

- The ring is hidden from assistive technology. The legend is a real list with each label, value and share, and the figure has a caption with the total.
- Segments draw in one after another when the chart appears. With reduced motion turned on they appear at once.
- It is plain SVG: one circle and one pattern per segment.
