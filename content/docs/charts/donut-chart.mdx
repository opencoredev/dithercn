## Usage

```tsx
import { DonutChart } from "@/components/dithercn/donut-chart";

const data = [
  { label: "North America", value: 48210 },
  { label: "Europe", value: 31870 },
  { label: "Asia Pacific", value: 17430 },
];

export function Regions() {
  return <DonutChart data={data} label="Requests today" />;
}
```

Slices run clockwise from 12 o'clock in the order you pass them. Each one draws in the next palette colour (ink, orange, green, pink, purple, blue, red, grey) unless you set `colors` for the chart or `color` on the slice.

Every slice is a block of whole dither cells with a solid rim along the outside. `fill="gradient"` thins out from that rim toward the centre; `dotted`, `hatched` and `solid` fill evenly. The gaps between slices are a constant width in cells, so they stay crisp in both modes.

Hover a slice or its legend row to spotlight it: the others fade, the slice steps out by two cells, and the centre switches from the total to that slice's value and share. Click to keep it lit and press Escape to let go. Focus the chart with Tab and the arrow keys step through the slices.

## Notes

- The chart is a focusable group with a summary label. Arrow keys, Home and End move between slices, Enter keeps one lit, and a live region reads the active slice. A hidden table lists every value and share.
- The sweep plays once when the chart scrolls into view. With reduced motion turned on, slices appear at once and the spotlight has no transition.
- The drawing is one SVG path per slice, built from whole cells snapped to device pixels. Hovering only changes opacity and a transform.
