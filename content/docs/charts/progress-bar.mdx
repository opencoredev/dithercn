## Usage

```tsx
import { ProgressBar } from "@/components/dithercn/progress-bar";

export function Upload({ percent }: { percent: number }) {
  return <ProgressBar label="Uploading report.pdf" value={percent} />;
}
```

`value` runs from 0 to `max`, which is 100 unless you set it. The fill is a half-density dither with a head that gets denser toward the value, over a track of faint dots.

Leave `value` out when you can't measure progress. The bar becomes indeterminate: a band of ink sweeps across the track, turning cells on and off as it passes.

```tsx
<ProgressBar label="Indexing repository" />
```

## Notes

- The bar has `role="progressbar"` with `aria-valuenow`, `aria-valuemax` and `aria-valuetext`. An indeterminate bar leaves `aria-valuenow` out, which is how assistive technology knows progress is unknown.
- The fill eases to each new value over 600ms. With reduced motion turned on it jumps, and the indeterminate band holds still in the middle of the track.
- The indeterminate sweep runs at 30 fps, only while the bar is on screen and the tab is visible. Each frame updates the 48 columns whose density changed and nothing else.
