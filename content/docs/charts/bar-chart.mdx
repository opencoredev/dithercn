## Usage

```tsx
import { BarChart } from "@/components/dithercn/bar-chart";

const data = [
  { week: "W36", deploys: 61 },
  { week: "W37", deploys: 68 },
  { week: "W38", deploys: 74 },
];

export function Deploys() {
  return (
    <BarChart
      data={data}
      x="week"
      series={[{ label: "Deploys", value: "deploys" }]}
    />
  );
}
```

Each bar is a dithered body under a solid 2px cap. One bar is drawn solid, the last by default, with its value above it. When the pointer or keyboard focus moves to another bar, that one fills in instead. `x` and each series' `value` name fields of your data, or take a function when you render from a Client Component.

## Examples

### Stacked

`variant="stacked"` puts the series on top of each other with a 2px gap between segments, and the axis covers the totals. `highlight="max"` picks the tallest stack.

<ComponentPreview src="examples/bar-chart-stacked.tsx" size="lg">
  <BarChartStacked />
</ComponentPreview>

### Grouped comparison

Grouped bars sit side by side, one per series. `highlight="none"` leaves every bar dithered until you hover one, and a lighter `level` with `matrix="bayer8"` gives a finer, quieter texture.

## Notes

- The chart is a focusable group with a short summary, and every value is in a visually hidden table. The arrow keys, Home and End move between bars; Escape hides the readout.
- Bars rise from the baseline one after another on entrance. With reduced motion they appear in place.
- Bars are capped at 36px wide and snapped to whole pixels, and the dither cell to whole device pixels, so edges and cells stay sharp.
