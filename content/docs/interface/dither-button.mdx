## Usage

```tsx
import { DitherButton } from "@/components/dithercn/dither-button";

export function Actions() {
  return (
    <>
      <DitherButton color="blue">Deploy</DitherButton>
      <DitherButton variant="outline" fill="dotted">
        View logs
      </DitherButton>
    </>
  );
}
```

`DitherButton` renders a real `<button>` with `type="button"` unless you pass another `type`. The fill sits in three layers behind the label: rest, hover and press. Each layer has more inked cells than the one below it, so as the hover layer fades in the texture eases denser, and pressing adds the third. Only opacity animates, so the cells stay on the grid.

`filled` buttons show the rest texture over a light tint of their colour. `outline` buttons start bare with a thin edge and take on the texture when you point at them, which suits secondary actions.

## Examples

### Fills and colours

Every fill in four colours. `gradient` is densest at the bottom edge and thins upward through the Bayer levels; `dotted` adds dots to a staggered lattice; `hatched` doubles its diagonals and then crosses them; `solid` is flat colour with a lighter dither rising on hover.

### Loading in a form

`loading` keeps the label and the button's width, steps three cells before the label, pulses the hover texture, and sets `aria-busy`. Clicks are ignored until it clears. Submit this one to see it.

<ComponentPreview src="examples/dither-button-form.tsx" size="md">
  <DitherButtonForm />
</ComponentPreview>

### As a link

Pass `asChild` and a single child, such as Next.js `Link` or a plain `<a>`, and the child gets the button's look and fill. It stays a link: right click and middle click work, and the router handles navigation.

## Notes

- Focus shows a 2 pixel outline with `:focus-visible` and the hover texture, so keyboard users see the same density step as pointer users.
- Hover only applies on devices that can hover. Press works everywhere, so touch screens get the denser fill as feedback.
- With reduced motion, the layers switch without fading, the press does not scale, and the loading cells hold still.
- Disabled and loading buttons drop to 45% opacity and a not-allowed or progress cursor. For a disabled link, set `aria-disabled` on it and leave out `href`.
- The fill is plain CSS masks in one shared `<style>` tag. The button only needs client JavaScript for `asChild` and `loading`.
