## Usage

```tsx
import { DitherButton } from "@/components/dithercn/dither-button";

export function Actions() {
  return (
    <>
      <DitherButton>Get started</DitherButton>
      <DitherButton variant="outline" href="/docs">
        Read the docs
      </DitherButton>
    </>
  );
}
```

Behind the label sit eight copies of the hover fill, each masked to one Bayer level. On hover they switch on lightest first, about 25 milliseconds apart, so the fill dissolves in through the matrix. When the pointer leaves, they switch off densest first. Pressing runs the same dissolve twice as fast, which also gives touch screens feedback.

## Notes

- Focus shows a 3 pixel ring with `:focus-visible`, so it appears for the keyboard and not for clicks.
- The hover fill only runs on devices that can hover. With reduced motion turned on, the fill changes in one step and the press does not scale.
- Every copy switches with a zero-length transition and its own delay, so a hover that ends halfway reverses from where it got to instead of restarting.
- The masks ship in one small hoisted `<style>` tag shared by every button on the page. The button needs no client JavaScript.
- With `href`, the button renders a plain `<a>`, so navigation is a full page load. For client-side navigation in Next.js, call `router.push` from `onClick` on a button instead.
