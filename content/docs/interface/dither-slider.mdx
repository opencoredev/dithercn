## Usage

```tsx
import { DitherSlider } from "@/components/dithercn/dither-slider";

export function Opacity() {
  return <DitherSlider label="Opacity" defaultValue={[64]} unit="%" />;
}
```

`DitherSlider` is built on the Radix `Slider`, so it takes the same `value`, `defaultValue`, `onValueChange`, `onValueCommit`, `min`, `max`, `step` and `name` props. Values are arrays, as in shadcn's slider: one value draws one thumb, two values draw a range.

The filled part of the track is a Bayer ramp worked out cell by cell. It is sparse far from the thumb, gets denser towards it, and is solid for the last two cells before a one-cell gap at the thumb, so the value reads at a glance. The cells sit on the track's own grid: dragging flips cells through their thresholds instead of sliding a texture along. With two thumbs the ramp runs in from both ends and thins out in the middle.

Hover, keyboard focus and dragging fade in a ramp twice as long with a denser floor. The thumb is a notched cap lit like [Dither button](/docs/interface/dither-button): a highlight dithered down from the top, a shade dithered up from the bottom and a grip line. Hover brightens it and dragging shades it from the top, so it looks pressed.

```tsx
<DitherSlider
  label="Price"
  defaultValue={[150, 600]}
  max={1000}
  step={50}
  format={{ style: "currency", currency: "USD", maximumFractionDigits: 0 }}
  showRange
/>
```

## Examples

### Price filter

Two values make a range. `format` takes `Intl.NumberFormat` options, here dollars, and is used for the readout, the `showRange` labels under the ends and each thumb's `aria-valuetext`. `minStepsBetweenThumbs={1}` keeps the two thumbs one step apart. The product count updates from `onValueChange`.

### Stepped volume

`step={1}` on a 0 to 10 scale snaps the thumb to eleven positions, and `ticks` marks each one under the track. Ticks inside the selected range take the full colour. This one is `size="lg"` in `purple` with a low bloom, and the mute button sets the value from outside.

All other props, such as `name`, `onValueCommit` and `minStepsBetweenThumbs`, pass through to Radix `Slider.Root`. `className` and `style` go on the outer wrapper.

## Notes

- Each thumb has `role="slider"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` and an `aria-valuetext` that includes the unit or currency. Arrow keys step, Page Up and Page Down step by ten, and Home and End jump to the ends.
- Inside a `<form>`, the slider submits one hidden input per thumb under `name` (`name[]` for a range).
- Focus shows a notched ring around the thumb with `:focus-visible`, and thickens the ramp just as hover does, so keyboard users see the same states as pointer users.
- With reduced motion the ramp and thumb states switch without fading. Nothing else moves.
- The fill is one SVG path per state, rebuilt as the value changes; the thumb is CSS masks in one shared `<style>` tag. No canvas or WebGL. Before the track is measured, a CSS ramp stands in.
- The slider is horizontal and left to right only.
