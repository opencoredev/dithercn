## Usage

```tsx
import { Divider } from "@/components/dithercn/divider";

export function Section() {
  return (
    <>
      <p>First section</p>
      <Divider />
      <p>Second section</p>
    </>
  );
}
```

The rule is solid in the middle and fades towards each tip in ten steps of dither. `fade` sets how much of each half is spent fading.

## Examples

### With a label

Pass `label` and the rule splits around it, each half fading away from the text.

<ComponentPreview src="examples/divider-label.tsx" size="lg">

### Vertical, between stats

A vertical divider fills the height of its container. Here it uses `--foreground` at half strength and 2 pixel cells, so it separates the numbers without competing with them.

## Notes

- By default the rule is decorative, like most visual dividers. Set `decorative={false}` when it separates content that screen reader users should know is split. A labelled divider reads its label as ordinary text.
- The rule is one SVG with no viewBox, so a dither cell is always a whole number of CSS pixels and every step of the fade lines up with its neighbours.
- It has no motion.
