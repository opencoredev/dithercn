## Usage

```tsx
import { Loader } from "@/components/dithercn/loader";

export function Saving() {
  return <Loader size="sm" color="blue" label="Saving changes" />;
}
```

Each variant is a tone field on a small grid of cells. Every frame, the loader thresholds the field with the Bayer matrix and paints the inked cells into a canvas at one pixel per cell. Shape edges are hard, so the ring and the blocks keep clean outlines; only the tone inside them fades, so the motion happens in the dither.

- `ring`: a comet on a faint track. Its tail stretches and shrinks as it goes round, so the ring breathes instead of spinning at one pace.
- `pulse`: a dot that beats while three rings ripple out from it and thin out as they grow. Good for "waiting for something to arrive".
- `grid`: a snake running round a 3 by 3 grid of blocks, one block per step, with a fading tail.
- `bar`: a dense head easing across a faint track, its tail thinning behind it. Four times as wide as it is tall.

## Notes

- The root has `role="status"` and a visually hidden `label`, so screen readers announce it politely when it appears. The canvas is hidden from them.
- With reduced motion turned on, each variant draws one still frame that still reads as a loader.
- It pauses when scrolled out of view or when the tab is hidden. A loader is 256 cells, so a frame is cheap, and it uses a 2D canvas rather than WebGL, so loaders never count against the page's WebGL budget.
- Cells snap to whole device pixels, so a loader stays crisp at any zoom level.
