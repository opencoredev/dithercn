## Usage

```tsx
import { Loader } from "@/components/dithercn/loader";

export function Saving() {
  return <Loader variant="ring" size="sm" label="Saving changes" />;
}
```

Each variant is a tone field on a small grid of cells. Every frame, the loader thresholds the field with the Bayer matrix and paints the inked cells into a canvas at one pixel per cell, so the tail of the ring and the fade of the bar step through real dither levels.

## Examples

### Sizes

`sm`, `md` and `lg` are 20, 32 and 48 pixels tall. The bar is three times as wide as it is tall. Cells are 2 pixels unless you set `cell`.

## Notes

- The root has `role="status"` and a visually hidden `label`, so screen readers announce it politely when it appears. The canvas is hidden from them.
- With reduced motion turned on, each variant draws one still frame that still reads as a loader.
- It pauses when scrolled out of view or when the tab is hidden. A `md` ring is 256 cells, so a frame is cheap, and it uses a 2D canvas rather than WebGL, so loaders never count against the page's WebGL budget.
- Cells snap to whole device pixels, so a loader stays crisp at any zoom level.
