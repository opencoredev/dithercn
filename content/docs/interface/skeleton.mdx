## Usage

```tsx
import { Skeleton } from "@/components/dithercn/skeleton";

export function ProfileLoading() {
  return (
    <div aria-busy="true" className="flex items-center gap-3">
      <span className="sr-only">Loading profile</span>
      <Skeleton shape="circle" size={40} />
      <Skeleton shape="text" lines={2} />
    </div>
  );
}
```

A skeleton is a block by default: give it a size with `className`. `shape="text"` draws a stack of lines that fills its width, the last one shorter. `shape="circle"` draws an avatar of `size` pixels.

Each skeleton has three layers in one colour: a faint tint, a sparse texture in the `fill` you pick, and a band of denser dither that sweeps across. The band is four slices, each a step up the Bayer ramp, so its middle is the densest and its edges fall off level by level. The levels stay low on purpose, so the placeholder sits below the content it stands in for. The default colour is grey; use your ink or a palette colour where the real content will be coloured.

## Examples

### A dashboard that is still loading

Labels you already know stay as text; only the numbers and the chart are placeholders. The figures use `ink`, so they hint at the coloured values on the way, and the chart uses a `gradient` texture that thickens towards the left.

## Notes

- Skeletons are hidden from assistive technology. Put `aria-busy="true"` on the region that is loading and a visually hidden sentence such as "Loading members", as the examples do.
- With reduced motion, the sweep is removed and the pulse holds still; the texture stays, so the placeholder still reads as one.
- The sweep animates `clip-path` on masked layers, and the pulse animates opacity. There is no JavaScript and no canvas, so a page full of skeletons costs one small shared `<style>` tag.
