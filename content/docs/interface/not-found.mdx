## Usage

```tsx title="app/not-found.tsx"
import Link from "next/link";

import { NotFound } from "@/components/dithercn/not-found";
import { Button } from "@/components/ui/button";

export default function NotFoundPage() {
  return (
    <main className="grid min-h-svh place-items-center">
      <NotFound
        actions={
          <Button asChild>
            <Link href="/">Back to home</Link>
          </Button>
        }
      />
    </main>
  );
}
```

The digits are drawn eight times, once per dither level. The denser copies cover less of the height, so the code is solid at the top and thins towards the baseline. When the block mounts, the copies appear one after another and the code prints in through the levels.

## Notes

- The big code is hidden from assistive technology; the heading carries the meaning.
- With reduced motion turned on, the code appears finished.
- It is plain HTML and CSS with no client JavaScript, so it works in a server component such as `app/not-found.tsx`.
- The digits use your page's font. A heavy weight shows the dither best.
