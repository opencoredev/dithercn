## Usage

```tsx title="app/not-found.tsx"
import Link from "next/link";

import { DitherButton } from "@/components/dithercn/dither-button";
import { NotFound } from "@/components/dithercn/not-found";

export default function NotFoundPage() {
  return (
    <main className="grid min-h-svh place-items-center">
      <NotFound
        actions={
          <DitherButton asChild>
            <Link href="/">Back to home</Link>
          </DitherButton>
        }
      />
    </main>
  );
}
```

The code is set in your page's own font, then rasterised onto a grid of cells and turned into block letters. The faces are densest at the top and thin towards the baseline; the cells behind them, down and to the right, form an extruded side in a sparse dither. On mount the digits print in level by level, and after that a band of light crosses the faces every few seconds.

`code`, `title`, `description`, `detail` and `actions` are all yours, so the same block covers 410, 500 and maintenance pages. `detail` is a short mono line under the text, a good place for the requested path or an error reference.

## Notes

- The digits are a decorative canvas hidden from assistive technology; the heading carries the message. Put the status in `title` or `description` if it matters to the reader.
- The grid follows the block's width, so the digits fill the space on a phone and stop at 672 pixels wide on a desktop. They are re-set when your web fonts finish loading.
- Under reduced motion, or with `animate={false}`, the digits are drawn once, finished. Offscreen and in hidden tabs, the light sweep pauses.
