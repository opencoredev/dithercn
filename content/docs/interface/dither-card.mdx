## Usage

```tsx
import { DitherCard } from "@/components/dithercn/dither-card";
import { CardContent, CardHeader, CardTitle } from "@/components/ui/card";

export function Revenue() {
  return (
    <DitherCard glow="top-right" interactive>
      <CardHeader>
        <CardTitle>Monthly revenue</CardTitle>
      </CardHeader>
      <CardContent>$48,210</CardContent>
    </DitherCard>
  );
}
```

`DitherCard` has the same spacing, border and colours as shadcn's `Card`, so `CardHeader`, `CardContent` and `CardFooter` fit inside it. It does not depend on them: plain markup works too.

The glow is a stack of rings, each filled with a denser dither than the one below it. With `interactive`, a second, larger stack switches on ring by ring when the card is hovered or something inside it has focus, so the glow grows outward through the levels.

## Examples

### Corners and edges

`glow` takes any corner, or `top` and `bottom` for a wide glow along an edge. Hover each card to see it grow.

<ComponentPreview src="examples/dither-card-glows.tsx" size="lg">

### Colour and grain

Any colour works, including chart colours and `--foreground` for a neutral light. Blue noise with 2 pixel cells gives a fine, even grain; Bayer 8×8 gives the smoothest falloff.

## Notes

- The glow is decorative and hidden from assistive technology. The card itself is a plain `div`; make the content inside it, not the card, the link or button.
- The hover glow only runs on devices that can hover. Keyboard users get the same effect when focus moves inside the card.
- With reduced motion turned on, the hover glow switches on in one step instead of ring by ring.
- The glow is static SVG, so it renders on the server and costs nothing while idle.
