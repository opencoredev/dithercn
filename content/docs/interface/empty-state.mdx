## Usage

```tsx
import { FolderIcon } from "lucide-react";

import { EmptyState } from "@/components/dithercn/empty-state";
import { Button } from "@/components/ui/button";

export function NoProjects() {
  return (
    <EmptyState
      icon={<FolderIcon />}
      title="No projects yet"
      description="Create a project to start building."
      action={<Button>New project</Button>}
    />
  );
}
```

The glyph sits on a raised tile in the middle of a scene drawn in dither cells. Bring the glyph from your own icon set with `icon`; without one, the tile shows a dashed square.

- `rings`: four bands around the tile, each lighter than the one inside it. They ripple outward by brightening one after another. `fill` sets their texture.
- `grid`: a lattice of single cells that thins out towards the edges, like a floor under the tile. Quieter, for search results and side panels.
- `none`: just the tile.

Both scenes dissolve at the top and bottom through blue noise, so they melt into whatever surface they sit on.

## Notes

- The scene is decorative and hidden from assistive technology. The title is a real heading; set `titleAs` to fit the page outline.
- The ripple fades each ring's opacity with CSS, and stops under reduced motion. The scene is a few SVG paths, cached per fill, so it costs no JavaScript at runtime.
- The scene keeps an 84 by 52 aspect ratio up to 336 pixels wide and shrinks on narrow screens.
