## Usage

```tsx
import { EmptyState } from "@/components/dithercn/empty-state";
import { Button } from "@/components/ui/button";

export function NoProjects() {
  return (
    <EmptyState
      motif="folder"
      title="No projects yet"
      description="Create a project to start building."
      action={<Button>New project</Button>}
    />
  );
}
```

The illustration is pixel art on a 44 by 32 grid of cells. Outlines are solid cells in `lineColor`; shading has a tone, and the Bayer matrix inks each of its cells or leaves it blank, so the shading is real dither at whole-pixel sizes.

## Examples

### Built-in motifs

Four motifs cover the common cases: `search` for no results, `folder` for no files, `chart` for no data and `inbox` for no messages. Here they use 2 pixel cells for a smaller drawing.

## Notes

- The illustration is hidden from assistive technology. The title is an `h3`; wrap the component or adjust it if your page needs another level.
- Write the title as a plain statement of what is empty, and the description as what to do about it.
- Each motif is rasterised once and cached, and the result is a single SVG path. It renders on the server and has no motion.
