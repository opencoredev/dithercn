`dither-export` is a small library next to `dither-core`. It takes the `ImageData` that `ditherImage` returns, one pixel per cell, and turns it into files. The [Dither maker](/docs/tools/dither-maker) is built on it.

## Usage

```tsx
import { ditherImage } from "@/lib/dither";
import { download, toCSS, toPNG, toSVG } from "@/lib/dither/export";

const dither = ditherImage(pixels, {
  method: "atkinson",
  palette: [
    [0.04, 0.04, 0.05],
    [0.95, 0.94, 0.91],
  ],
});

// A full-size PNG: every cell becomes a crisp 4 × 4 block.
download({ data: await toPNG(dither, { scale: 4 }), filename: "dither.png" });

// An SVG drawn in cells, 4px each.
const svg = toSVG(dither, { cell: 4 });

// A CSS rule with the dither as a covering background.
const css = toCSS({ kind: "image", image: dither, selector: ".hero" });
```

`toSVG` and `toCSS` are plain functions that return strings. `toPNG`, `download` and the PNG form of `toCSS` need a browser, because they draw to a canvas.

## Examples

### A tile in pure CSS

The default kind of `toCSS` repeats one matrix tile at a coverage `level`, from 0 to 1. In `mask` mode it paints the element with `ink` and masks it to the dither, so the ink can be a CSS variable and follows your theme. These rules are built on the server; the page runs no script for them.

```ts
toCSS({ level: 0.25, cell: 4, ink: "--dither-ink", mode: "mask" });
```

```css
.dither {
  background-color: var(--dither-ink);
  -webkit-mask: url("data:image/svg+xml,…") 0 0 / 16px 16px repeat;
  mask: url("data:image/svg+xml,…") 0 0 / 16px 16px repeat;
}
```

In the default `background` mode the ink is baked into the tile and `paper` fills the gaps. An SVG inside a data URI can't read CSS variables, so pass a literal colour for `ink` in that mode.

### Indexed bitmaps

If you work out the dither yourself, pass `toSVG` one palette index per cell instead of pixels. Any index without a colour is left transparent.

```ts
const svg = toSVG(
  { width: 64, height: 32, indices },
  { cell: 3, palette: ["#0a0a0b", "#3d6bff", "#dfe7ff"] }
);
```

## API

### toPNG

```ts
toPNG(
  source: HTMLCanvasElement | PixelBuffer,
  options?: { scale?: number }
): Promise<Blob>
```

Encodes a canvas or pixels as a PNG. `scale` is a whole-number upscale with no smoothing, so pass the cell size to turn one pixel per cell into a full-size image.

### toSVG

```ts
toSVG(
  source: PixelBuffer | IndexedBitmap,
  options?: {
    cell?: number;
    palette?: DitherColor[];
    background?: boolean;
  }
): string
```

An SVG in cell units, scaled to `cell` pixels per cell (default 1). Runs of one colour merge into rectangles, one `<path>` per colour. The most used colour becomes a single background rectangle unless `background` is `false`. `palette` colours an `IndexedBitmap` by index.

### toCSS

```ts
toCSS(options: CSSOptions): string
```

Returns one CSS rule. The default `tile` kind repeats one matrix tile; the `image` kind embeds a whole dither. Options:

### download

```ts
download(options: {
  data: Blob | string;
  filename: string;
  type?: string;
}): void
```

Saves a Blob or a string through the browser's download flow. Strings are saved with `type`, default `text/plain`. `svgDataUrl(svg)` is exported too: it wraps an SVG string in a CSS `url()`.

## Notes

- Choose the format by the picture. Ordered dithers of gradients and shapes have long runs, so their SVG is tiny. Error-diffusion dithers of photos have almost none, and PNG compresses them better.
- PNG exports are capped at 16,384 pixels on the longest side, the most every current browser can draw.
- The functions never change their input.
