Start from a generated pattern, or drop, paste or choose an image. Images never leave your device. Pick a look from the strip under the canvas, then fine-tune it in the inspector. **Compare** splits the canvas into the original and the dither; drag the divider or move it with the arrow keys. **1:1** shows the export's real pixels and **2:1** doubles them; drag to pan.

## The controls

- **Looks.** Ready combinations of method, cell, contrast and palette. Each thumbnail is your current source run through that look, so you choose by seeing the result.
- **Source.** A generated orb, linear ramp, glow or noise field, each with its own control, or an image of your own.
- **Pattern.** The dither method, with a strip under each one showing how it renders a ramp. Bayer and blue noise are ordered: a fixed pattern that tiles cleanly and suits gradients and flat shapes. Floyd–Steinberg, Atkinson and Sierra Lite spread each cell's error to its neighbours, which keeps more detail in photos. Cell sets how many output pixels one cell covers. Contrast and brightness apply to the tones before dithering.
- **Colour.** Two to four palette stops, always laid out dark to light, so the theme's paper and ink work the same way in light and dark mode. Pick a stop, then a colour for it from the dithercn palette or the custom picker. Tones sets how many colours the result uses; extra ones are mixed between the stops.
- **Output.** The shape of the export: 16:9, 1:1, 4:5, 3:1, or the image's own shape. The pixel and cell counts update as you go.
- **Export.** Opens the [export panel](/docs/tools/export): PNG, SVG or CSS, a preview of the file, its size and weight, and copy and download buttons.

## Installation

The maker is a component you can put in your own app, such as an admin tool or a brand page.

<InstallBlock name="dither-maker" />

## Usage

```tsx
import { DitherMaker } from "@/components/dithercn/dither-maker";

export default function Page() {
  return <DitherMaker />;
}
```

It fills its container. From a 48rem container it puts the inspector beside the canvas; narrower, the inspector sits under the canvas with one tab per group.

## Examples

### Your own looks

Pass `presets` to replace the strip with your brand's looks, and `filename` to name the downloads. Colours can be palette names such as `"purple"`, which follow light and dark mode, or any CSS colour.

### Offer sample pictures

`samples` adds links to the empty image state, so people can try the maker before they have a picture to hand. `defaultImage` opens on a picture instead. Images on another origin need CORS headers, or the browser won't let the canvas read them.

```tsx
<DitherMaker
  defaultImage="/team-photo.jpg"
  samples={[
    { name: "Earthrise", src: "/examples/earthrise.jpg" },
    { name: "Tetons", src: "/examples/tetons.jpg" },
  ]}
/>
```

## Notes

- Every control is a native input, a labelled button or a radio group with arrow-key navigation. The compare divider is a slider: arrows move it by 2%, Shift by 10%, Home and End jump to the edges.
- Dithering runs on the main thread, on the frame after a control changes. A 1600 × 900 output at 4px cells is 90,000 cells and redraws in a few milliseconds. The thumbnails wait until the controls settle, so dragging a slider only redraws the canvas.
- In Fit, each cell gets a whole number of device pixels when that fills most of the stage, so the pattern never shimmers. Use 1:1 to judge the real output.
- The maker is built on the [export helpers](/docs/tools/export), so anything it saves you can also produce in code.
