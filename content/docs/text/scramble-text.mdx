## Usage

```tsx
import { ScrambleText } from "@/components/dithercn/scramble-text";

export function Title() {
  return <ScrambleText as="h2">Decoding the signal</ScrambleText>;
}
```

Characters cycle through glyphs, then settle left to right into the final text. The default glyphs are shade blocks and quadrants (`░▒▓▚▞`), so the text decodes out of a dither. Pass `characters` for letters, digits, hex or anything else.

Each scrambled glyph sits in the slot of the character it will become, so the width never changes and nothing around it moves. Kerning and ligatures are turned off on the text to keep those slots exact.

## Examples

### On hover

With `trigger="hover"`, the text replays whenever the closest link or button is hovered or receives keyboard focus, not only the text itself.

## Notes

- The final text is always in the page as real text. While the effect plays it turns transparent and an overlay hidden from assistive technology draws the glyphs on top, so screen readers, search engines and copy and paste only ever see the final text.
- Unsettled glyphs use the ink colour; settled ones use the text colour.
- With reduced motion turned on, the text never scrambles.
- The overlay exists only while the effect plays, and the loop stops as soon as every character settles.
