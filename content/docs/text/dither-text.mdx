## Usage

```tsx
import { DitherText } from "@/components/dithercn/dither-text";

export function Hero() {
  return (
    <DitherText as="h1" className="text-8xl font-semibold tracking-tight">
      Your headline
    </DitherText>
  );
}
```

The text stays a real element: people can select and copy it, screen readers read it, and search engines index it. The dither is a small image drawn on the client and clipped to the letters with `background-clip: text`. By default it runs from solid ink at the top to a sparse dither at the bottom, with a slow drift that bends the bands.

Set the size with your own classes. The cell size follows the font size, about 1/24 of it and never below 2px, so the same component reads well as a hero and as a section heading.

## Examples

### Noise fill with a palette

`fill="noise"` fills the letters with drifting noise instead of a gradient. Here blue noise and a three-colour palette, from transparent through `--chart-4` to the ink, give a soft grain.

### Section heading in the foreground colour

A smaller heading that fades left to right (`angle={90}`), drawn in `--foreground` so it matches body text on light and dark themes. `animate={false}` draws it once.

## Notes

- The text is the accessible content. The fill is a background image, so assistive technology ignores it.
- Before the client draws the fill, the letters show in the ink colour through a plain dither mask, so there is no flash of unstyled text. In forced-colours mode the fill is removed and the text uses the system colour.
- Selected text shows in the site's selection colours, solid, so it stays readable while highlighted.
- With reduced motion turned on, or `animate={false}`, it draws one frame. It redraws at 12 fps only while on screen, at one pixel per dither cell, and pauses in hidden tabs.
- Keep `to` high enough for the letters to read: below about 0.3 the bottom of each letter breaks into scattered dots.
