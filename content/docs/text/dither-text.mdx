## Usage

```tsx
import { DitherText } from "@/components/dithercn/dither-text";

export function Hero() {
  return (
    <DitherText
      as="h1"
      color="blue"
      className="text-8xl font-bold tracking-tight"
    >
      Your headline
    </DitherText>
  );
}
```

The text stays a real element: people can select and copy it, screen readers read it, and search engines index it. The text turns transparent and a canvas over it draws the letters as whole dither cells, so their edges step along the grid instead of cutting cells in half.

`fill` picks what goes inside the letters:

- `gradient` (the default) runs from solid ink on one side to a sparse dither on the other, with a slow drift that bends the bands. `direction` is the way it thins out: `"down"` is solid at the top.
- `noise` fills the letters with drifting blobs of density. `scale` sets their size and `direction` the way they drift.
- `dotted` and `hatched` use the same textures as the charts and buttons, drifting a cell at a time in `direction`. A faint `ghost` of the ink fills the gaps so the letters keep their shape.
- `solid` is flat colour, useful with `bloom` alone.

Set the size with your own classes. The cell size follows the font size, about 1/24 of it and never below 2px, so the same component reads well as a hero and as a section heading. Pass `cell` to fix it.

## Notes

- The text is the accessible content. The fill is a background image, so assistive technology ignores it.
- Before the client draws the fill, the letters show in the ink colour through a plain dither mask, so there is no flash of unstyled text. In forced-colours mode the fill is removed and the text uses the system colour.
- Selected text shows in the site's selection colours, solid, so it stays readable while highlighted.
- With reduced motion turned on, or `animate={false}`, it draws one frame. It redraws at 12 fps only while on screen, at one pixel per dither cell, and pauses in hidden tabs. `solid` never animates.
