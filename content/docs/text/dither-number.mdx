## Usage

```tsx
import { DitherNumber } from "@/components/dithercn/dither-number";

export function Stat() {
  return <DitherNumber value={128406} className="text-7xl font-semibold" />;
}
```

When the number scrolls into view, every digit rolls up from `from` (0 by default) to its place in `value`. Digits pass through a dithered edge above and below the line, so they fade through the dither as they enter and leave. Lower places spin a full extra turn when the value jumps by ten or more at that place, like a mechanical counter. Change `value` later and only the digits that differ move.

## Examples

### Landing stats

`format` takes any `Intl.NumberFormat` options: percent, compact notation and currency here. Separators, symbols and suffixes stay still; only the digits move.

### Live value with dissolve

`effect="dissolve"` swaps each changed digit by dissolving the old one out and the new one in, which suits values that update often. This card follows a value that changes every few seconds.

## Notes

- The formatted value is real text laid over the animation, transparent, so it can be selected and copied and is what screen readers and search engines read. The moving digits are hidden from assistive technology.
- Digits use tabular figures, so the width only changes when the number of digits does.
- The server renders the final value. On the client the digits wait at `from` until the trigger fires.
- With reduced motion turned on, the number changes instantly.
- Only ASCII digits animate. Formats that use another numbering system show their digits without motion.
