## Render a component

Components are full-bleed by default: they fill the box you give them. Put one behind your content with `absolute inset-0`:

```tsx
import { DitherGradient } from "@/components/dithercn/dither-gradient";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <DitherGradient angle={160} className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

## Shared props

Components built on `DitherShader` share these props, so once you know one you know them all:

| Prop      | What it controls                                                            | Default                          |
| --------- | --------------------------------------------------------------------------- | -------------------------------- |
| `matrix`  | The threshold pattern: `"bayer2"`, `"bayer4"`, `"bayer8"` or `"blue-noise"` | `"bayer4"`                       |
| `levels`  | How many tones to snap to before dithering                                  | Every tone the matrix can draw   |
| `cell`    | Cell size in CSS pixels                                                     | `--dither-cell`                  |
| `palette` | Colours from paper to ink, two or more                                      | `--dither-paper`, `--dither-ink` |
| `animate` | Whether it moves                                                            | `true`                           |
| `speed`   | How fast it moves                                                           | `1`                              |

Each component page lists its own props as well. [Dither engine](/docs/concepts/dither-engine) explains what the matrix and levels do.

## Use the tokens directly

Tailwind gets two colour utilities from `dither-tokens`: `dither-ink` and `dither-paper`. Use them anywhere you would use a theme colour:

```tsx
<div className="bg-dither-paper text-dither-ink rounded-md p-4">12,480</div>
```

Read `--dither-cell` when you need the shared cell size, for example to line up a hand-made pattern with the components:

```css
.pattern {
  background-size: calc(var(--dither-cell) * 4) calc(var(--dither-cell) * 4);
}
```

## Build your own

Every component is a thin layer over `dither-core` in `lib/dither`. To make a background of your own, write a GLSL field and hand it to `DitherShader`:

```tsx
import { DitherShader } from "@/lib/dither";

const FIELD = `
float field(vec2 uv, vec2 res, float t) {
  return fbm(uv * 3.0 + vec2(t * 0.05, 0.0));
}
`;

export function Clouds() {
  return <DitherShader field={FIELD} className="absolute inset-0" />;
}
```

It already handles resizing, the theme, reduced motion and pausing offscreen. [Concepts](/docs/concepts/dither-engine) covers the rest of the engine.
