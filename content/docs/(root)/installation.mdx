dithercn installs with the shadcn CLI, like any other registry. Today the registry has one item, `dither-tokens`. Catalog pieces will install the same way as they land, and each will pull in `dither-tokens` automatically.

## Before you start

You need a project that already uses shadcn/ui, with a `components.json` file and Tailwind CSS v4. If you don't have one yet, follow the [shadcn installation guide](https://ui.shadcn.com/docs/installation) first.

<Callout title="No public URL yet">
  dithercn isn't deployed yet, so the commands below install from a local copy
  of this site at `http://localhost:3000`. Clone the repository, run `pnpm
  install` and `pnpm dev`, then run the commands from your own project.
</Callout>

## Add the tokens

<Steps>

### Run the add command

```bash
npx shadcn@latest add http://localhost:3000/r/dither-tokens.json
```

### Check your CSS

The CLI adds three variables for light and dark mode to the CSS file named in your `components.json`, and two colours to its `@theme inline` block:

```css
:root {
  --dither-ink: var(--primary);
  --dither-paper: var(--background);
  --dither-cell: 3px;
}

@theme inline {
  --color-dither-ink: var(--dither-ink);
  --color-dither-paper: var(--dither-paper);
}
```

The `.dark` block gets the same three variables. Because they point at your theme tokens, there is nothing to set for dark mode.

</Steps>

## Use a namespace

To install by name instead of by URL, add dithercn to the `registries` field of your `components.json`:

```json title="components.json"
{
  "registries": {
    "@dithercn": "http://localhost:3000/r/{name}.json"
  }
}
```

Then install with the `@dithercn` prefix:

```bash
npx shadcn@latest add @dithercn/dither-tokens
```

See the shadcn docs on [namespaced registries](https://ui.shadcn.com/docs/registry/namespace) for more options, including authentication.
