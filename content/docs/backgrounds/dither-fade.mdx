## Usage

```tsx
import { DitherFade } from "@/components/dithercn/dither-fade";

export function Changelog() {
  return (
    <section className="relative overflow-hidden">
      <ChangelogEntries />
      <DitherFade side="bottom" size={200} />
    </section>
  );
}
```

Put the fade inside a `relative` parent. It covers `size` along `side` and paints `color` over whatever is underneath: sparse cells on the content side, solid at the edge. The default colour is `--dither-paper`, your page background.

It is still and drawn with CSS masks, so it renders on the server and uses no WebGL. Use as many as you like on one page.

## Examples

### Between two sections

Give the fade the colour of the section below it, or leave the default when that section uses the page background. The upper section dissolves into the next one with no hard line.

## Notes

- The fade is decorative and hidden from assistive technology. Content under it stays in the page and is still read out, so do not hide anything important beneath it.
- The still fade has no motion. With `animate`, reduced motion holds one still frame, and it pauses offscreen like the other backgrounds.
- The still fade is 16 masked layers and no script. The animated one costs one small draw per frame and one WebGL context.
