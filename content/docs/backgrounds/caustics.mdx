## Usage

```tsx
import { Caustics } from "@/components/dithercn/caustics";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Caustics className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Light gathers along the borders of slowly circling cells, and a slow swell bends those borders into curves, the way waves on a surface bend the light below. Each filament keeps the same width in dither cells at any box size, so the lines stay crisp. Where three borders meet, the filament thickens into a hot spot. A second, larger and fainter net drifts more slowly underneath and crosses the first, and broad patches of sunlight brighten some areas more than others. It defaults to the 8×8 matrix, which keeps the glow around each filament smooth.

## Examples

### Behind a headline

`mask="center"` fades the light out in an oval behind the text and leaves the dim water, so no filament crosses the words. A lower `scale` makes each cell of light larger and a sharper `focus` thins the filaments around it.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a still CSS net in the same colours, drawn from SVG turbulence, with the same `mask`.
