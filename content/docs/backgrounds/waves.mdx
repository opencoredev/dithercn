## Usage

```tsx
import { Waves } from "@/components/dithercn/waves";

export function Footer() {
  return (
    <footer className="relative isolate min-h-[320px]">
      <Waves className="absolute inset-0 -z-10" />
    </footer>
  );
}
```

Rows of swells roll towards you below the horizon. Distant rows are small and bright, near ones large and dark, and every crest has a one-cell highlight.

## Examples

### Dusk

A lower `horizon`, eight `layers` and a warm palette give a sea at sunset. A smaller `amplitude` calms the water.

<ComponentPreview src="examples/waves-dusk.tsx" size="lg" align="stretch">
  <WavesDusk />
</ComponentPreview>

### Sound wave

`variant="lines"` draws thin lines that swell in the middle and taper at both ends. It suits audio players, voice input and anything that listens.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS approximation in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/engine/performance).
