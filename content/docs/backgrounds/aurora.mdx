## Usage

```tsx
import { Aurora } from "@/components/dithercn/aurora";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Aurora className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Three curtains hang from the top of the box. Each has a bright lower edge that bends slowly and rays that fade as they rise. `height` sets where the lowest edge hangs, so you can keep the area under it clear for text.

## Examples

### Above a headline

Raising `height` lifts the curtains off the lower third, where the headline sits on clean paper.

A custom palette and paper turn it into the real thing: green curtains on a night sky. More `sway` gives the edges deeper folds.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS approximation in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/concepts/performance).
