## Usage

```tsx
import { Metaballs } from "@/components/dithercn/metaballs";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Metaballs className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Each blob rises and sinks on its own slow loop. Where two come close, their edges reach for each other and join, then pull apart again. Every blob is densest at its core and has a soft halo around its edge.

## Examples

### Contour rings

`variant="rings"` draws contour lines around the blobs instead of filling them. The rings merge and split with the blobs.

<ComponentPreview src="examples/metaballs-rings.tsx" size="lg" align="stretch">

### Lava lamp

Five blobs in warm colours, sped up a little, in a tall rounded box. In a narrow box the blobs are sized by its width.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows soft CSS blobs in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/engine/performance).
