## Usage

```tsx
import { Ridgelines } from "@/components/dithercn/ridgelines";

export function Section() {
  return (
    <section className="relative isolate min-h-[420px]">
      <Ridgelines className="absolute inset-0 -z-10" />
    </section>
  );
}
```

Each line is flat at the ends and peaked in the middle, and each one hides the lines behind it. The peaks shift slowly. A faint shade under the tallest peaks makes them read as solid ridges. Lines stay one cell wide and at least four cells apart, so a short box draws fewer of them.

## Examples

### In a card

Fewer `lines`, a narrower `spread` and small cells fit a pulsar plot in a card.

### Mountain range

`spread={1}` raises peaks across the whole width. A lower `amplitude` keeps them low, and a three-colour palette shades the slopes.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows thin CSS lines in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/engine/performance).
