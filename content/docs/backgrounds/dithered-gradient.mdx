<ComingSoon />

Smooth CSS gradients band on low-end screens and look generic everywhere else. A dithered gradient trades the smooth ramp for a visible texture that reads as deliberate.

## Planned

- Linear, radial and conic modes with CSS-like angle and stop props.
- Two-tone from theme tokens, or multi-stop from a palette.
- Optional slow drift of the gradient angle.
