## Usage

```tsx
import { NoiseField } from "@/components/dithercn/noise-field";

export function Section() {
  return (
    <section className="relative isolate min-h-[480px]">
      <NoiseField mask="center" className="absolute inset-0 -z-10" />
      <h2>Your headline</h2>
    </section>
  );
}
```

The field is fractal noise folded back on itself, so it flows like smoke rather than scrolling. It uses `bayer8` by default, whose 64 tones keep the folds smooth. Blue noise gives a grainier, film-like look.

## Examples

### Cleared under a headline

`mask="center"` fades the field to paper in the middle of the box. Use `"top"` or `"bottom"` when the text sits at one end instead.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS approximation in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/concepts/performance).
