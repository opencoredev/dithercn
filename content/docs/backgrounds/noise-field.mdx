## Usage

```tsx
import { NoiseField } from "@/components/dithercn/noise-field";

export function Section() {
  return (
    <section className="relative isolate min-h-[480px]">
      <NoiseField mask="center" className="absolute inset-0 -z-10" />
      <h2>Your headline</h2>
    </section>
  );
}
```

The field is fractal noise folded back on itself, so it flows like smoke rather than scrolling. `variant` changes what the noise draws:

- `smoke`, the default: soft folds that dither into smooth gradients.
- `ridges`: sharp creases, like veins or lightning.
- `contours`: topographic lines, spaced by `bands`.
- `marble`: warped stripes, also set by `bands`.

`warp`, `detail` and `scale` shape the noise itself. `contrast`, `coverage` and `intensity` decide how much of it turns to ink. `angle` and `flow` set where it drifts, and `mask` with `maskSize` clears room for your text.

## Examples

### Cleared under a headline

`mask="center"` fades the field to paper in the middle of the box. Use `"top"` or `"bottom"` when the text sits at one end, and `maskSize` to clear more or less.

### Fine grain in a dashboard card

A high `scale`, a low `intensity` and 2px cells turn it into a texture you notice only when it moves.

<ComponentPreview src="examples/noise-field-card.tsx">
  <NoiseFieldCard />
</ComponentPreview>

### Topographic lines

`variant="contours"` draws the noise as height lines, a good fit for maps and region stats. A bottom `mask` keeps the numbers on clean paper, and a low `flow` lets the terrain shift slowly.

<ComponentPreview src="examples/noise-field-topography.tsx">
  <NoiseFieldTopography />
</ComponentPreview>

### Marble with a highlight

`variant="marble"` with more `warp` bends the stripes into veins. `highlight` adds a third colour for the brightest peaks, here the foreground, so the stripes catch the light.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS approximation in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. Each step of `detail` adds a layer of noise, so lower it on large, busy pages. See [Performance](/docs/engine/performance).
