## Usage

```tsx
import { Halftone } from "@/components/dithercn/halftone";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Halftone className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Unlike the other backgrounds, halftone is not an ordered dither. Each square of a rotated grid holds one solid dot, sized by the value of the source at its centre, the way a printing screen works. The default source is slow, warped noise.

It uses one-pixel cells by default so the dots stay round, and 12 cells between dot centres.

## Examples

### Spotlight behind a headline

`source="radial"` grows the dots towards `center`. With the centre below the bottom edge and a `radius` under 1, the dots swell up from the bottom and run out before the text.

### Linear ramp in a card

`source="linear"` grows the dots towards `direction`. With a palette of more than two colours, bigger dots take later colours. This one is held still, at a shallow 15° screen angle.

## Notes

- The halftone is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS dot screen.
- `matrix` is not a prop here: dots are solid, so there is nothing to threshold.
