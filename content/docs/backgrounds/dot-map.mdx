## Usage

```tsx
import { DotMap } from "@/components/dithercn/dot-map";

const OFFICES = [
  { at: [51.51, -0.13], label: "London" },
  { at: [35.68, 139.69], label: "Tokyo" },
] as const;

export function Offices() {
  return (
    <DotMap
      markers={OFFICES}
      arcs={[{ from: OFFICES[0].at, to: OFFICES[1].at }]}
      accent="blue"
    />
  );
}
```

The map is an SVG that scales to its container's width and keeps its aspect ratio. Land comes from a 3.8 KB mask of Natural Earth's public-domain land polygons that installs with it as `world-land`, so nothing is fetched at runtime.

Each marker pulses and casts a dithered halo on the land around it: dense at the marker, thinning through the Bayer levels. Arcs are dotted curves with a stretch of light running along them.

## Notes

- The map is one image to assistive technology, named by `title` plus the marker labels.
- Pulses and running arcs are CSS animations. With reduced motion they are hidden and the map is still.
- Pass `markers` and `arcs` as constants or memoised arrays: the dot paths are rebuilt when they change. Land cells are cached per grid size.
- Land data: [Natural Earth](https://www.naturalearthdata.com/) 1:50m land, public domain, rasterised to 0.75° cells.
