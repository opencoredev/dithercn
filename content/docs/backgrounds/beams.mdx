## Usage

```tsx
import { Beams } from "@/components/dithercn/beams";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Beams className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Light comes from `origin` and spreads in a cone around `angle`. The rays are noise around the origin, so they widen with distance like real shafts of light, and dust drifting through them breaks them up along their length. The whole cone sways back and forth by `sweep` degrees over about a minute.

## Examples

### From the top edge

An origin far above the box gives nearly parallel rays, like light through a high window. Brightness fades from where the light enters the box, not from the far origin.

## Notes

- The light is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a soft CSS cone.
