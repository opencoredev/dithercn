## Usage

```tsx
import { Eclipse } from "@/components/dithercn/eclipse";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Eclipse className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

A disc in `skyColor` sits in front of a light in `rimColor`. A thin rim hugs the edge and is brightest on the `light` side, like the crescent of a real eclipse. Around it, a halo fades outwards with slow variations in strength, and the whole glow breathes on a slow ten-second cycle.

## Examples

### Beside a headline

The disc sits in the top right with a short corona, lit from the lower left, and the text sits in the clear space below it. This layout holds from phone to desktop widths.

## Notes

- The eclipse is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a CSS disc and ring.
- The disc is the sky colour, so on a light theme it reads as a pale disc with a coloured ring. Pass a dark `skyColor` for a dark disc on any theme.
