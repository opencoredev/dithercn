## Usage

```tsx
import { Smoke } from "@/components/dithercn/smoke";

export function Footer() {
  return (
    <footer className="relative isolate min-h-[360px]">
      <Smoke className="absolute inset-0 -z-10" />
    </footer>
  );
}
```

The smoke is thickest at the bottom and thins out as it climbs. Light from the upper left catches one side of each plume and leaves the other in shadow. The thickest parts stop short of solid ink, so the dither always shows.

## Examples

### Behind a headline

A lower `height` keeps the smoke in the bottom half, and a lower `density` makes it lighter. Negative `wind` blows it to the left.

<ComponentPreview src="examples/smoke-headline.tsx" size="lg" align="stretch">

### Embers

Four warm colours turn the smoke into the glow above a fire. Blue noise gives an even grain instead of the Bayer grid.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a soft CSS haze in the same colours.
- It costs one small draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/engine/performance).
