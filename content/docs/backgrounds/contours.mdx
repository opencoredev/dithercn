## Usage

```tsx
import { Contours } from "@/components/dithercn/contours";

export function Section() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Contours className="absolute inset-0 -z-10" />
      <h2>Your heading</h2>
    </section>
  );
}
```

Contour lines trace even steps of height across a field of low hills. Every fifth line is drawn heavier, as on a survey map, and slopes facing away from a light in the top left pick up a light stipple. The hills drift and slowly change shape. They keep their size in pixels, so a narrow box shows a smaller piece of the same map rather than a squashed one.

## Examples

### Survey map

More `lines`, a smaller `scale` and a little more `relief` in green and brown give an old ordnance survey sheet. `cell={2}` keeps the lines fine.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows faint CSS rings.
