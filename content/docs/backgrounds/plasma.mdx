## Usage

```tsx
import { Plasma } from "@/components/dithercn/plasma";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Plasma className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Plasma fills its box, so give it a size with `className`. Four sine waves, one of them circling the centre, add up to a pattern that never repeats. A slow noise warp bends it so it doesn't look mechanical. By default it runs from `--dither-paper` through `--chart-5` to `--dither-ink`.

## Examples

### Through a palette

Pass any number of colours from paper to ink. More `bands` cycle through the palette more often, and blue noise swaps the Bayer grid for an even grain.

<ComponentPreview src="examples/plasma-palette.tsx" size="full" align="stretch">
  <PlasmaPalette />
</ComponentPreview>

### Behind a headline

`intensity` caps the brightest tone, so the crests never reach full ink and the text stays readable. A smaller `scale` and more `warp` give fewer, softer shapes.

<ComponentPreview src="examples/plasma-headline.tsx" size="lg" align="stretch">
  <PlasmaHeadline />
</ComponentPreview>

### Coarse and still

Large cells, the 2×2 matrix and only four `levels` give hard contour bands like an old demo-scene effect. `animate={false}` holds one frame.

## Notes

- The plasma is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows soft CSS blobs in the same colours.
- One draw per frame at 30 fps, at one pixel per dither cell. See [Performance](/docs/concepts/performance).
