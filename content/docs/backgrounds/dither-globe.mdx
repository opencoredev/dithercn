## Usage

```tsx
import { DitherGlobe } from "@/components/dithercn/dither-globe";

const LONDON = [51.51, -0.13] as const;
const TOKYO = [35.68, 139.69] as const;

export function Global() {
  return (
    <DitherGlobe
      markers={[{ at: LONDON }, { at: TOKYO }]}
      arcs={[{ from: LONDON, to: TOKYO }]}
      className="aspect-square w-full max-w-md"
    />
  );
}
```

The globe is drawn on a 2D canvas at dither-cell resolution: every cell on the sphere gets a tone from the land mask and the light, then an ordered threshold decides whether it's inked. Land is bright on the day side and fades to a sparse grid past the terminator; the sea is a faint dither that thickens towards the rim. It uses no WebGL context, so it doesn't count against the page's shader budget.

The globe stays round and centred in its box and takes 84% of the shorter side. Make the box larger than its section and offset it to show only the top of the globe, as in the first example.

Land comes from the shared `world-land` mask (Natural Earth, public domain), installed with the component. Nothing is fetched at runtime.

## Notes

- The globe is decorative and hidden from assistive technology. Say what it shows in the copy next to it.
- With reduced motion turned on, it draws one still frame and dragging is off.
- It pauses when scrolled out of view or when the tab is hidden. A 600px globe at 2px cells is about 70,000 cells per frame at 30 fps, well within budget on a phone; raise `cell` for very large globes.
