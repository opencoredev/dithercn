## Usage

```tsx
import { Voronoi } from "@/components/dithercn/voronoi";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <Voronoi variant="foam" className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

Every grid square holds one seed, and every point belongs to the seed nearest to it. Each seed wanders inside its square on its own slow loop, so cells grow as their neighbours move away, and two cells that meet at a corner can pull apart while the other two close in.

The walls are measured as the exact distance to the nearest edge, in dither cells, so a wall is the same width along its whole length and at any box size. There are three variants:

- `"foam"`: bright thin walls that thicken where three meet, like the borders in a soap foam. Light gathers just inside each wall, and each cell has a faint glint.
- `"glaze"`: flat cells at four exact dither levels, split by open cracks, with a finer crackle running across them, like a crackle glaze or dried mud.
- `"stone"`: raised tiles with rounded corners. Each tile is bevelled towards its edges and lit from the top left, so the edges facing the light are denser.

## Examples

### Behind a headline

`fade={1}` clears an oval in the middle of the box. In `"glaze"`, cells fade as a whole by where their seed sits, so every cell stays one flat level and the ones near the middle drop out first.

### Coloured mosaic

`colors` gives each cell one colour from a list. With `"stone"`, a wider `wall` for the grout and a slower `drift`, the tiles read as a mosaic that shifts very slowly.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows the same kind of cells as an SVG, in the same colours.
- Each cell checks 34 seeds, and `"glaze"` twice that for its fine crackle, at one pixel per dither cell and 30 fps. With `colors`, the colour pass checks them again. See [Performance](/docs/engine/performance).
