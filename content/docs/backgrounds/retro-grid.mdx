## Usage

```tsx
import { RetroGrid } from "@/components/dithercn/retro-grid";

export function Hero() {
  return (
    <section className="relative isolate min-h-[480px]">
      <RetroGrid className="absolute inset-0 -z-10" />
      <h1>Your headline</h1>
    </section>
  );
}
```

The floor is a grid seen from a low camera, scrolling slowly towards you. Lines stay about one cell wide at every depth and fade out where they would crowd closer than a few cells, so the horizon doesn't break into moiré. The sun sits half sunk behind the horizon, with slits through its lower half that thicken towards the ground and drift down. Grid squares keep their size against the box height, so a phone shows fewer columns, not thinner ones.

## Notes

- It is decorative and hidden from assistive technology. Put real text on top of it, not inside it.
- With reduced motion turned on, it draws one still frame and stops.
- It pauses when scrolled out of view or when the tab is hidden, and releases its WebGL context when far offscreen. Without WebGL it shows a horizon line, a soft sun and a fade in CSS.
