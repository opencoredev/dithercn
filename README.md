<h1 align="center">dithercn</h1>

<p align="center">
  Beautiful dithers for landing pages and dashboards. A shadcn registry of dithered backgrounds, charts, UI pieces, type and images that follow your theme, installed with <code>npx shadcn add</code>.
</p>

## Status

Early preview. The docs site and the catalog plan are up, and one registry item ships: `dither-tokens`, the CSS variables every piece will read. Every catalog page is marked as coming soon until its piece lands.

The catalog has eight groups: Foundations, Backgrounds, Dashboard, UI, Type, Images, Logos and Tools. Each planned piece has a page under `content/docs/<group>/`.

## Develop

```bash
pnpm install
pnpm dev
```

Then open http://localhost:3000. Other scripts:

- `pnpm build` builds the registry, then the site
- `pnpm registry:build` writes `registry.json` items to `public/r/`
- `pnpm check` runs formatting and lint checks (ultracite)
- `pnpm typecheck` runs TypeScript

Set `SITE_URL` to the public origin when deploying. Without it, canonical URLs and install commands use `http://localhost:3000`.

## Install the tokens

With the dev server running, from a project that uses shadcn/ui:

```bash
npx shadcn@latest add http://localhost:3000/r/dither-tokens.json
```

This adds `--dither-ink`, `--dither-paper` and `--dither-cell` to your CSS, mapped to your `--primary` and `--background` tokens.

## For agents

The site serves `/llms.txt`, `/llms-full.txt`, a Markdown version of every docs page (append `.md`), an agent skill at `/.well-known/agent-skills/`, an API catalog at `/.well-known/api-catalog` and an OpenAPI description at `/openapi.json`.

## Project structure

```
├── content/docs/       # Docs (MDX). (root) is "Get started"; each other folder is a catalog group
├── registry.json       # Registry manifest
├── public/r/           # Built registry items (generated by pnpm registry:build)
├── app/                # Next.js app: site, docs, OG images, agent routes
├── components/         # Site components (ui/ holds the shadcn primitives)
└── lib/                # Docs source, catalog, agent discovery
```
